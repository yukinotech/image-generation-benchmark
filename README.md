# 文生图 Benchmark

对比六个模型在相同目标画幅、提示词与 Seed 下的输出。静态页面包含生成图、中文译文和单图复现参数。

- `docs/` 是 GitHub Pages 的发布目录。页面可由普通静态 HTTP 服务直接提供。
- `benchmark/` 包含跑图、提示词、尺寸规则、查看器和静态导出代码。运行本地 benchmark 需要另行准备 ComfyUI、模型和本地运行环境。
- 表格使用缩略 WebP，点击预览和全屏使用大图 WebP。「打开原图」直接链接到脱敏 PNG。公开的 JSON 保留提示词、原始尺寸、Seed、模型文件名与复现参数。

添加提示词、运行新批次、生成脱敏发布包和推送 Pages 的步骤见 [发布流程](benchmark/README.md#添加提示词后的发布流程)。
